# Family Tree Template

Україномовний шаблон родинного дерева. У демонстрації десять вигаданих людей, дві родинні лінії, брат, тітка та двоюрідна сестра.

## Створіть своє дерево

1. Натисніть **Use this template → Create a new repository** або **Fork**. Для власних сімейних відомостей виберіть приватний репозиторій.
2. Завантажте або склонуйте свій репозиторій.
3. Відкрийте `index.html` у Chrome. Початкова демонстрація працює одразу.
4. Замініть вигадані записи у `data/family.json` своїми відомостями.
5. Виконайте `python3 scripts/build.py` і перезавантажте сторінку.

Python 3 потрібен тільки для оновлення даних. Залежностей для встановлення немає. Для запуску через HTTP можна виконати `python3 -m http.server 8000` і відкрити <http://localhost:8000>.

## Можливості

- Дерево зі зв’язками батьків і дітей, подружжя та бічних гілок.
- Кольори гілок, вибір поколінь, материнської й батьківської лінії.
- Режим родини окремої людини зі шляхом до основної особи.
- Картки, історії, професії, джерела, родинна мапа.
- Експорт схеми у PDF та PNG.
- Посилання на гілку й картку після публікації на власному сайті.
- Підтримка каталогу фотографій. Демонстраційних фото немає.

## Дані та зв’язки

Канонічний файл цього шаблону — `data/family.json`. `app/tree-data.js` генерується автоматично.

У `people` кожна людина має постійний `id` формату `P-0001` і унікальний `key`. Основна особа має `key: "root"`. Усі зв’язки посилаються на `key`. Для поколінь використовуйте `level: 0` для основної особи, `-1` для батьків, `-2` для дідусів та бабусь. `branch` приймає `self`, `m` або `f`.

У `edges` зберігаються окремі зв’язки. Для `parent` поле `a` — батько чи мати, `b` — дитина. Додайте два такі записи, якщо відомі обоє батьків. Для `spouse` кінці позначають пару. Також підтримуються `sibling` та `stepparent`. Ступінь спорідненості обчислюється під час перегляду.

`sources` містить джерела, а `refs` — їхні індекси з нуля. Не змінюйте порядок джерел без оновлення посилань. `history.summary` і `history.sections` містять абзаци з посиланнями на джерела. Невідомі дати залишайте порожніми. `livingStatus` приймає `living`, `deceased`, `unknown`.

У `lineages` задаються кольорові гілки через `anchors` — ключі людей. У `geography.places` — місця з координатами, у `geography.events` — події людей у цих місцях. Місце народження й подальші переїзди можна записувати окремими подіями.

Будівник перевіряє унікальність людей, кінці зв’язків, посилання на джерела та цикли батьківства. Достовірність сімейних переказів перевіряйте за власними матеріалами.

## Фото

Для кожного фото додайте запис у `photos` з `id`, `sourceId`, `title`, `description`, `takenLabel`, `dateBasis`, `receivedLabel`, `sender`, `channel`, `identification`, `cataloguedLabel`, `people` та `sides`. Люди позначаються постійними `id`.

Кожен бік у `sides` містить `side: "front"` або `"back"`, `path`, `preview`, `sha256`, `previewSha256`, `caption`, `width`, `height`, `rotation` і `mime`. Шляхи ведуть до власних знімків у вашому репозиторії або сховищі. Перед публікацією отримайте згоду родичів.

## Публікація

Це статичний сайт. У Vercel імпортуйте власний репозиторій, виберіть **Other**, без команди збірки, вихідна папка — `.`. Перед публікацією запустіть локальний генератор і збережіть `app/tree-data.js` у Git.

Усі дані й медіа, розміщені на відкритому статичному сайті, доступні відвідувачам. Для справжнього дерева налаштуйте обмеження доступу у свого хостингу або переглядайте його локально. `noindex` впливає на пошукову індексацію, але доступу до даних не обмежує.
